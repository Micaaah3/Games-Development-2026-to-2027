# 🚀 Unity Bombing Run Project: Pseudo-Scrum & Testing Assignment

## 🎯 Overview
In this team assignment, you will work within a pseudo-Scrum framework to add new mechanics to our existing Unity core project (Moving Plane, Follow Camera, and Sequential Bomb Dropping). 

This project explicitly uses a **Test-Driven / Agile Hybrid Lifecycle**. Instead of writing code immediately, you must collaborate with your assigned peer tester to define validation rules **before** implementation begins.
